# LBS Manajemen (contoh tampilan)

Mockup aplikasi manajemen untuk kontraktor kebun sawit: progres pekerjaan per SPK, BAPP dan termin, uang, alat berat,
jejak sparepart bernomor seri, dan jejak siapa menginput apa.

Buka: **https://shinx2ran.github.io/lbs-mockup/**

- Nama perusahaan klien adalah perusahaan perkebunan sungguhan yang dipakai sebagai contoh. Semua orang, angka, nomor SPK,
  BAPP, invoice, dan foto adalah rekaan. Ini bukan data nyata.
- Satu berkas `index.html` tanpa server dan tanpa library luar. Tidak ada data yang dikirim ke mana pun.
- Di HP: buka alamat di atas, lalu "Tambahkan ke layar utama" (Android: menu ⋮; iPhone: tombol Bagikan). Setelah dibuka
  sekali, bisa dibuka tanpa sinyal.

Sumber dan panduan demo ada di repositori Woombad, folder `mockups/kontraktor-sawit`.
